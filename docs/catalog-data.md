# Данные каталога

Основной файл для ручного заполнения — `product-extra-template.xlsx`. В нём закреплена строка заголовков. CSV создаётся как совместимая копия.

Подробное описание каждого столбца и порядок работы находятся в [инструкции по заполнению](как-заполнять-таблицу-товаров.txt).

## Обновление каталога

1. Закройте Excel-книгу.
2. Выполните `node scripts/generate-product-extra-template.js`, чтобы добавить новые позиции из `products.json`, сохранив заполненные данные.
3. Выполните `node scripts/build-product-catalog.js`, чтобы создать `products-merged.json`.

При первом запуске генератор переносит строки из существующего `product-extra-template.csv` в XLSX. После этого редактируйте XLSX: именно он становится основным источником дополнительных данных.
