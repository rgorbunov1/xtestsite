ИНСТРУКЦИЯ ПО ЗАПОЛНЕНИЮ ТАБЛИЦЫ ТОВАРОВ

Основной файл для ручного заполнения: product-extra-template.xlsx
Лист внутри книги: «Товары». Первая строка закреплена. Не переименовывайте файл, лист и заголовки столбцов.

КАК РАБОТАТЬ С ТАБЛИЦЕЙ

1. Откройте product-extra-template.xlsx в Excel.
2. Не меняйте product_id и variant_id: по ним программа находит товар и его вариант.
3. Заполняйте нужные поля. Оставляйте ненужные ячейки пустыми.
4. Если у товара несколько вариантов, у каждого варианта своя строка и свой variant_id. product_id в этих строках повторяется.
5. Перед запуском скриптов сохраните и закройте книгу Excel.
6. Чтобы добавить новые позиции из products.json и сохранить заполненные ячейки, выполните:
   node scripts/generate-product-extra-template.js
7. Чтобы собрать каталог для сайта, выполните:
   node scripts/build-product-catalog.js

Для установки зависимости при первом запуске проекта выполните: npm install
Файл product-extra-template.csv создаётся как совместимая копия. Основной файл для редактирования — XLSX.

ЧТО ОЗНАЧАЮТ СТОЛБЦЫ

ДАННЫЕ ТОВАРА

product_id — уникальный идентификатор товара из 1С. Заполнен автоматически; не изменяйте его.
product_name — название товара из 1С. Для ориентира; обычно не нужно редактировать.
product_article — артикул товара из 1С. Для справки.
product_category — категория товара из 1С. Для справки.
product_price — цена товара из 1С. Для справки; цена варианта задаётся отдельно.
product_stock — остаток товара из 1С. Для справки; остаток варианта задаётся отдельно.

КАРТИНКИ И ОПИСАНИЕ ТОВАРА

main_image — путь к основной картинке товара, например img/krossovki.jpg. Можно указать полный URL.
gallery_1 — путь к первой дополнительной картинке товара.
gallery_2 — путь ко второй дополнительной картинке товара.
gallery_3 — путь к третьей дополнительной картинке товара.
gallery_4 — путь к четвёртой дополнительной картинке товара.
gallery_5 — путь к пятой дополнительной картинке товара.
description — текстовое описание товара. Можно писать обычным текстом.

ХАРАКТЕРИСТИКИ ТОВАРА

spec_1_name — название первой характеристики, например «Материал».
spec_1_value — значение первой характеристики, например «ПВХ».
spec_2_name — название второй характеристики.
spec_2_value — значение второй характеристики.
spec_3_name — название третьей характеристики.
spec_3_value — значение третьей характеристики.

СКИДКА

discount_percent — размер скидки в процентах, например 15. Впишите число без знака %.
discount_amount — размер скидки фиксированной суммой в валюте цены. Обычно заполняют либо процент, либо сумму.
Если в строке заполнен variant_id, скидка относится к этому варианту. Если variant_id пустой — скидка относится ко всему товару.

ДАННЫЕ ВАРИАНТА ТОВАРА

variant_id — уникальный идентификатор варианта из 1С. Заполнен автоматически; не изменяйте его.
variant_name — название варианта, например размер или цвет. Для справки.
variant_price — цена этого варианта из 1С. Для справки.
variant_stock — остаток этого варианта из 1С. Для справки.
variant_image_1 — основная картинка варианта.
variant_image_2 — дополнительная картинка варианта.
variant_image_3 — ещё одна дополнительная картинка варианта.
variant_image_4 — дополнительная картинка варианта.
variant_image_5 — дополнительная картинка варианта.
variant_image_6 — дополнительная картинка варианта.
variant_image_7 — дополнительная картинка варианта.
variant_image_8 — дополнительная картинка варианта.
variant_image_9 — дополнительная картинка варианта.
variant_image_10 — десятая картинка варианта.
variant_spec_1_name — название первой характеристики варианта, например «Размер».
variant_spec_1_value — значение первой характеристики варианта, например «42».
variant_spec_2_name — название второй характеристики варианта.
variant_spec_2_value — значение второй характеристики варианта.

ПРАВИЛА ДЛЯ ПУТЕЙ К КАРТИНКАМ

Если файл лежит в папке проекта, указывайте относительный путь от корня проекта, например img/tovar-1.jpg. Для внешней картинки указывайте полный адрес, начинающийся с https://. Не указывайте путь к файлу на вашем компьютере, например C:\Users\... — сайт его не увидит.

КАРТИНКУ МОЖНО ВСТАВИТЬ ПРЯМО В EXCEL

1. Выберите ячейку для изображения: main_image, gallery_1 ... gallery_5 или variant_image_1 ... variant_image_3.
2. В Excel выберите Вставка → Рисунки → Это устройство и выберите файл PNG, JPG/JPEG или GIF. Используйте обычное изображение поверх ячеек, не режим «Поместить в ячейку».
3. Разместите верхний левый угол картинки внутри нужной ячейки. Для товара с вариантами вставляйте изображение в строку нужного товара или варианта.
4. Сохраните и закройте книгу.
5. Запустите node scripts/build-product-catalog.js. Скрипт сохранит изображение в img/products/ и использует его на сайте.

Если позже запустить node scripts/generate-product-extra-template.js, встроенное изображение будет сохранено в img/products/, а соответствующая ячейка заменится путём к файлу. Сам файл останется в проекте и продолжит использоваться сайтом. Поддерживаются обычные вставленные картинки, привязанные к ячейкам таблицы; формулы Excel IMAGE() и режим «Поместить в ячейку» не поддерживаются.

Если у товара есть варианты, товарные картинки и описание относятся ко всему товару. Картинки и характеристики с префиксом variant_ относятся только к варианту в этой строке. Для вариантов одного товара повторяйте product_id, но оставляйте разные variant_id.
